# Fiat Tipo 9" Android Emulator Skin

Skin funcional para Android Emulator com área de ecrã 1280x720 em landscape.

## Instalação

1. Extrai a pasta `fiat_tipo_9`.
2. Copia-a para:
   `%LOCALAPPDATA%\Android\Sdk\skins\fiat_tipo_9`
3. Android Studio -> Device Manager -> Create Device -> New Hardware Profile
4. Configura:
   - Screen size: 9.0"
   - Resolution: 1280 x 720
   - Density: 160 dpi
   - Orientation: Landscape
5. Em **Default Skin**, seleciona a pasta `fiat_tipo_9`.
6. Cria o AVD e inicia-o.

## Nota
Os controlos laterais são decorativos. A área real do Android é 1280x720, posicionada em x=160 e y=100.
